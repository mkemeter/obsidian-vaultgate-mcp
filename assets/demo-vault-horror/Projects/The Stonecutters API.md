# The Stonecutters API

An internal authentication service that nobody remembers building.

- **Owner:** unknown.
- **Documentation:** none.
- **Monitoring:** none.
- **Commits:** all signed "No. 1."
- **Config header:** the first two lines of a song about who controls the British Crown.
- **Uptime:** total. It has never failed. Not once. This is listed as item #1 in [[Tech Debt]] precisely because it should not be possible.

[[Beelzebart]] found it during a scan and found traffic in its access logs that resolves to outside CGHMN — some of it to [[Kang and Kodos]]' address space, which is either reassuring or the opposite. [[The Collector]] was asked to review it, looked for fourteen seconds, and declined without giving a reason.

The [[On-Call Runbook]] lists exactly one instruction for this service: do not touch it. [[Count Burns]] asked about it by name in the last exec review and seemed pleased by the answer, which was no answer.
