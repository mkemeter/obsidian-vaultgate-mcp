# ADR-001 Why We Chose Node

**Decision:** CGHMN standardises on Node.js for backend services.

**Context:** We needed one runtime across the team. Python stayed for [[Lisafer]]'s data work. Go was considered and rejected on staffing grounds.

**Status:** Accepted. Relitigated approximately once per full moon.

## Dissent

This ADR was authored by [[The Collector]], who dissents from its conclusion. His filed objection reads, in full: "Worst. Runtime. Ever." He attached a 14-page manifesto, *Why Everything Else Is Wrong*, and a 3-page addendum.

[[Were-Milhouse]] has requested a formal review of this ADR, because The Collector's rejections of his [[Operation Big Top]] pull requests increasingly cite the framework choice rather than the code — "a contributing factor to the fundamental brokenness of the entire approach." Milhouse is using Node. The ADR says to use Node. He is unsure what he is doing wrong.
