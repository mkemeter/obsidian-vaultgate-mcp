# The Stonecutters API

## What It Is

An internal REST API running on CGHMN infrastructure. It handles authentication tokens for an undetermined set of internal services. It is fast, reliable, and completely undocumented.

Nobody at CGHMN knows who built it.

## Who Owns It

Unknown. The commit history goes back further than CGHMN's current Git migration. All commits are signed **"No. 1"**. The config file header reads:

```
# Who controls the British Crown?
# We do, we do.
# Who keeps the metric system down?
# We do, we do.
```

This appears to be a reference to a private joke, a song, or a secret society. Possibly all three.

[[Comic Book Guy]] was asked to review the codebase. He reviewed it for fourteen seconds. He declined. He has not explained why.

[[Bart Simpson]] identified the API during a routine security scan. His report: "This thing exists, it's been running for years, nobody knows what it does, and I found Fat Tony's IP in the access logs. Ay, caramba." I have the full report pending review.

[[Springfield Mafia#Contact]] was reportedly seen near the server room on one occasion. No access record exists for that visit.

## History

The API has **never failed**. It has no SLA, no monitoring dashboard, and no oncall owner. [[Apu Nahasapeemapetilon]] has suggested adding monitoring three times. Nothing has been done, partly because nobody is certain what to monitor for, and partly because everyone is slightly afraid of what they might find.
