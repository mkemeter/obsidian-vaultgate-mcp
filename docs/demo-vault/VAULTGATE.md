## How I organize
- **People/** — one note per teammate or exec. 1:1 logs live in the person's note.
- **Customers/** — one note per client company; the primary contact is named in frontmatter.
- **Projects/** — one note per project/engagement. Status is in frontmatter.
- **Meetings/** — sprint planning, retros, exec reviews.
- **Engineering/** — incidents, runbooks, ADRs, tech-debt reference.

## Conventions
- Sprints are named `S<season>E<episode>`, e.g. `S35E09`. The current sprint is S35E09.
- Project status is one of: `active`, `planning`, `blocked`, `shipped`, `on hold`.
- I link people, projects, and customers with wikilinks so everything is connected.
- Tags I rely on: `#blocked`, `#tech-debt`, `#incident`, `#active`, `#on-hold`, `#shipped`.

## When helping me
- Prefer reading the relevant Project or Person note before answering.
- When I forward or mention an email, relate it to the matching Customer/Project note.
- Draft updates to notes when asked, but show me the change first.
